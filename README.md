# Grantsy Helm Charts

This branch hosts the Helm chart repository index for [grantsy/charts](https://github.com/grantsy/charts).

```bash
helm repo add grantsy https://grantsy.github.io/charts
helm repo update
helm search repo grantsy
```

The source for the charts lives on the [`main`](https://github.com/grantsy/charts/tree/main) branch.
